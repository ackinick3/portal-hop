# 第九及二十六至三十五关标准路线

坐标为960x540逻辑视野。R清双门、接收器锁存及机关位置；普通地面与传送速度规则保持原值。

## 第九关 Apex Relay

起点右缘(169,175)，先蓝门(365,430)、红门(230,470)。D走下台后尽早短按A刹车（约x190开始），松键落进红门。首次从第一台上冲，升到y<200左右时，将红门移到第二台(575,430)；保持落点在脚下蓝门中。下一次从第二台上冲，y<190左右把蓝门移到第三台(775,430)，再次落回脚下红门。第三次出门立刻D到右侧终点台。底部全是刺，平台间竖挡块使低处不能提前射中下一台，顶点附近有较宽的真实可见区间，没有脚本禁止低处开枪。实际出口约727.5/742.5/757.5，少量增速来自原有出口偏移后的再次下落，无关卡专属奖励。测试tests/relay9.gd不赋角色位置/速度。

## 第26至35关：红跑道、蓝回弹、激光机关

本章每关都真实使用红助跑、蓝反弹和传送门激光。下面门位是激光门，角色由跑道跨坑。接收器点亮后锁存。

| 关 | 标准操作与区别 |
|---|---|
|26 Run Spring Power|红(300,110)、蓝(610,140)点亮接收器；一直D沿红条跑进蓝条，弹过刺坑并穿过已开的门。|
|27 Twin Contacts|红(300,110)，先蓝(610,140)，等灯亮再蓝(610,180)点亮第二灯；D跨坑。|
|28 Under the Circuit|红头顶台底(220,270)，光源从下向上照入；蓝(610,140)转为向左光路；D跨坑。|
|29 Downward Current|红(300,110)，蓝天花板底(540,200)，向下照亮(540,320)接收器；D跨坑。|
|30 Return Current|独立左行布局：红(740,270)，蓝(350,140)，然后一直A向左经过加速/弹性表面抵达终点。|
|31 Source Selector|先红(300,110)、蓝(610,140)点亮第一灯；再红(300,180)、蓝(610,180)切换光源点亮第二灯；D跨坑。|
|32 Airborne Ignition|先红(120,340)，顶棚遮住远处蓝门目标；D蓝弹起后，约x450时蓝(610,140)，空中点亮接收器，继续D过门。|
|33 Flight Switches|先红(120,340)，D弹起；约x450蓝(610,140)，约x560再蓝(610,180)，空中点亮两灯再过门。|
|34 Two Stage Run|红(120,340)、蓝(610,140)先开面前跑道门；D过门到x260左右，再蓝(610,180)打开远处门，继续红跑蓝弹跨坑。|
|35 Backflow Relay|左行布局：红(840,340)，一直A；x<510时蓝(350,140)，x<400时再蓝(350,180)，点亮两灯并继续左行。|
