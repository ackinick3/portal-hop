# 第七关：Midair Switchback / 空中折返

用户已选择并要求开始“空中折返”：首次弹射向右，飞行途中依次把红门放到前方墙面、蓝门放到侧边地板，把水平速度变成向上冲刺后抵达高台。继续使用已确认物理、B美术、无文字关内提示和唯一PortalHop.exe入口。

## 最终地图与路线

- 出生(378,115)，起点台x340..460、顶130。先向左墙(180,170)放蓝门；D向右离台后射红地板(530,480)，接近x475时A刹住并松开，落入红门。
- 左墙为x155..180、y25..305；首次从右向墙门出门，在起点台下方向右飞。
- 前方墙x780、y300..540，左向面y330..510，红门建议(780,430)。飞行途中先左键重放红门。
- 第二出口地板台x260..400、顶300，向上有效段264..396，蓝门建议(300,300)。挡板x250..260、y210..270；起点时由出生台遮挡、刚出门时由挡板遮挡，飞过挡板后才能看到出口。空中再右键重放蓝门，需在人物低于侧台前完成。
- 进入前方红墙门后，向上地板出口把水平速度转成上升，同时下落分量转向左。挡板右侧挡住左移后，继续上升；高于终点台时按D，落到x290..400、顶60的平台，再到(330,6)的门。
- 死亡/R清双门和阶段，暂停重启直接开始。没有新技能、敌种、速度补偿或传送次数硬锁。具体坐标及可操作区间以真实物理输入测试迭代，原前六关不改。
