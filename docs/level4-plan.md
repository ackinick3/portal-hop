# 第四关：The Vector Switch / 换向高台

用户已要求开发完成后再试玩提意见。本轮直接交付第四关，不等待额外设计确认；第五关不在本轮范围。

## 地图与路线

逻辑视野仍960x540，复用当前玩家和传送门，所有物理参数不变。第四关无敌人。

| 元素 | 初始设计 |
|---|---|
| 安全底层 | x=0..960，顶部y=470 |
| 出生高台 | x=60..200，顶部y=220，出生中心(128,205) |
| 入口墙 | x=310..335，y=250..470，左面法线LEFT |
| 入口有效段 | x=310，y=250..390；建议红门中心(310,300) |
| 地板出口台 | x=750..920，顶部y=300 |
| 地板有效段 | x=760..900，y=300；建议蓝门(830,300) |
| 终点高台 | x=560..700，顶部y=285；终点x=560..602 |
| 可选天花板 | x=360..600，底面y=160；建议蓝门(540,160) |

标准路线：在出生台先放地板蓝门，向右走下台，清楚离开高台后再射墙红门；保持向右运动，带着跑速和下落速度进入红门。从地板蓝门向上离开时，原下落分量转换成向左运动，向右跑速转换成向上运动。向左控制，落到终点高台后抵达终点。门始终自由放置，圆圈只是建议。

备选路线：改把蓝门放到天花板，从上方向右下方空降；出门后向左刹车，落到同一终点台。必须用真实物理验证余量，不添加额外发射速度。

失败与重试：底层为安全地板，失误不会被尖刺强制惩罚；R在0.3秒死亡反馈后重置到出生台并清门。不得直接靠普通跳跃从底层登上终点台。
