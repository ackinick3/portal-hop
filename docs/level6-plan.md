# 第六关：Airborne Relay / 空中接力

目标：用户要求在同一游戏内添加空中重放门、连续两次下落增速的第六关，并改善浅色墙段边缘放门。沿用Godot 4、已确认的玩家物理、B美术、无文字关内界面、唯一builds/PortalHop.exe入口。

## 设计与取舍

当前速度变换保持大小，不能把“叠加动能”实现为凭空加速。采用地板→天花板继续下落，再于空中把蓝门改成墙出口，第二次下落由重力增速后转为水平速度。只需空中补一枪，有可调整的约0.4秒窗口；比飞行中同时重放两个门更适合作为首次教学。重复关内顶部文字不符合既有要求，因此进入第六关前用一张简短说明卡，关内只显示分阶段建议圈；R保持立即重试。

最终地图：出生(665,115)，平台x600..740、顶130，右侧x740..760悬墙从顶部延伸到200；红门地板x420..540、y480；蓝门天花板x390..550、y60，建议(465,60)；空中改蓝门到左墙(120,100)，墙右向有效段y35..305；终点台x880..960、顶360。大坑x560..880。先蓝天花板，A向左离台放红(465,480)，接近x520后D逐渐刹住并松开；首次传送后空中向左墙补蓝，继续下落进入保留的红门，第二次横向弹射到终点。失败沿用R/死亡复位清门，不加新技能、速度倍率或强制传送次数锁。

地图迭代：起初左侧出生台挡住较晚的空中换墙射线，因此移至右上方，不改射线遮挡规则。右侧起点曾能普通跳跃直接到终点，测试复现后补悬墙；第二次弹射仍能从悬墙下方通过。推荐路线的标准单次弹射对照失败，但不宣称排除所有跳跃/入门角度组合的巧解。

边缘问题根因：candidate要求命中点本身作为门中心满足两端36px余量。改为：必须命中同一个真实可用面且总长度至少72；沿面将中心限制在[low+36,high-36]，再用调整后的中心检查异色间隔及完整出口空间。仍拒绝非浅色区域、遮挡、过短表面及堵塞出口，不把门缩小或让射线穿墙。
