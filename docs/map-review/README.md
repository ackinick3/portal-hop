# 地图批注工作台

正式入口：[地图批注.html](../地图批注.html)。这是单个离线HTML，双击后用普通浏览器打开即可，不需安装依赖或启动服务。请保持同一浏览器、同一文件路径使用，以便继续读取原浏览器保存的内容。

## 使用

1. 用上一关/下一关查看A–E五张计划图，或在非输入状态按左右方向键翻页。
2. 用画笔、箭头、文字给地图加批注；文字工具需点击地图定位，文字也能从右侧列表重新编辑。可调整颜色、粗细、缩放；放大后在地图区域滚动查看。
3. 在右侧整体意见里写整关想法，例如“连接底部几块地面，蓝台保持独立”。撤销仅撤销当前关最后一个图上标记；清空本关需确认，会同时清空本关整体意见。
4. 评完点“导出全部批注”，保存JSON并将它发回对话。助手不能直接读取浏览器localStorage。PNG用于分享当前底图与图上批注；整体意见和完整长文字以JSON为准。
5. 后续助手先按意见修改SVG计划图，再生成同一个HTML入口；用户复核确认后才实装游戏。更新前先导出JSON备份。A–E编号稳定；新底图与旧批注版本不一致会提示位置需复核，旧意见不会被自动清除。

自动保存属于当前浏览器/打开地址，不会自动写回HTML，也不等于磁盘备份。普通浏览器打开文件与内置浏览器的临时HTTP预览是不同存储空间，可用JSON交换。浏览器空间不足时网页会明确提示导出；读到无法解析的旧数据时禁止自动覆盖，提供旧数据原文下载，新意见可另导出JSON。只有明确确认导入另一份合法JSON后才替换存储。

## 维护

`../五关布局示意.svg`是地图源，`page.html`/`style.css`/`app.js`是界面，`review-core.js`负责批注格式/导入及坐标，`build.cjs`把这些资源内嵌到单文件HTML。不要只改生成HTML，以免重建时丢改动。

从项目根目录执行（Node可用时）：

```powershell
node docs/map-review/build.cjs
node --test docs/map-review/review-core.test.cjs
node --check docs/map-review/app.js
```

没有全局Node时，使用当前机器的`C:/Users/XH/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe`。
