# 空白关卡编辑器（含曲线路线）

用户要求直接搭建：白纸点击放起点/终点，拖动绘制灰白蓝红绿墙、可控长度方向地刺；黄/紫/红激光发射器可控方向，接收器、可选移动范围怪物。补充要求曲线箭头预设路线，提交后由助手计算控制比例。

实现：本地单文件docs/关卡编辑器.html，源文件在docs/level-editor/。沿用960×540，空白初始；部件选择栏+画布+属性栏。墙/刺按线段绘制，数值调整位置/长度/角度，刺可翻转。点部件点击放置，发射器调整方向，怪物可拖巡逻线。曲线为二次贝塞尔箭头，画起终点后拖控制点，保存路线顺序。选择模式可移动部件和端点，删除、撤销/重做，浏览器自动保存、JSON导入/导出、PNG导出。

保持简单：无账户/服务器/激光模拟/碰撞/游戏接入；不定义三色发射器的未确认行为。提交按钮导出JSON，提示用户发回对话；助手根据路径意图重新计算比例，不能将手画坐标视为物理验证。五图批注网页保留。

2. 写界面和绘制，内嵌生成单HTML；运行相关Node全套及JS语法检查。
3. 浏览器实测点放置、拖墙、属性改方向/长度、刺翻转、发射器、怪物范围、曲线控制点、选择移动、撤销、保存/导入及PNG。只监听本机单页临时预览；无用户数据示例残留。
4. 审阅保存/导入与几何交互，修实质问题；同步现状/README/进度并提交。游戏不改、不跑Godot、不重新导出。
