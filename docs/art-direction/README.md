# 起点旗帜与终点门美术方案

用户要求先生成图片选择，再优化游戏美术并移除关卡顶部文字。使用内置image_gen，以第四关截图`docs/room4.png`为编辑参考，生成同场景三套效果预览：

- A：[简洁霓虹科技](A-neon-v1.png)
- **B：[圆润玩具科技，用户选择的第二张](B-rounded-v1.png)**
- C：[精密工业机械](C-industrial-v1.png)

完整提示词保存在`prompts.json`。以上是生图效果预览，不是新版游戏运行截图。

采用B方向：白色圆角旗杆/底座、绿色柔和旗面与圆头灯，白色圆角拱门、内嵌绿灯条和发光门槛。实际游戏使用`ui/landmarks.gd`原生2D绘制，适应各关位置、窗口比例及轻微摆动/灯光动画，未把整张概念图当背景贴入。

关内移除顶部计时/关卡/门状态/长篇提示及建议点文字，保留准星、放门预览和无文字的建议圆圈；主菜单操作说明、暂停菜单和结算文字继续使用。计时和死亡数仍记录并在结算显示。

验收以实际运行截图`docs/room1.png`至`docs/room4.png`为准。物理、地形、出生点、传送门开口及终点触发区域不随外观改变。
