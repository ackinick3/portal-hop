# 当前限制与人工验收

当前源码为五十关，最终整包验证及实际EXE身份见PROJECT_STATE和build-manifest；自动通关不代表用户已接受人手难度。第9–50关是本轮自主设计，前八关地图未改。

## 已知边界

- UI/入关卡仍为英文，逐关操作与门位有中文路线文档。关内按用户要求无顶部HUD及文字标签。
- 普通地面210/1400/2300、跳跃-330/重力900、空中380/松键90、出口总速度沿法线均保持。蓝色反弹与红色加速只在指定涂层生效，其参数尚待人手反馈。
- 第九关及第32/33/35关需要空中换门。高点/飞行窗口有真实几何约束，脚本路线已通过，但真实鼠标瞄准及反应难度需要试玩。
- 蓝色表面为自动反弹，红色只加速脚下地面上的移动；没有增加攀墙/墙跑。彩色表面不放门，绿色只反射枪线而不反射激光。
- 激光作为非致命解谜工具；接收器锁存至R/重启，避免要求玩家长时间保持光路。多个接收器可共同控制同一门/平台，连接用图形线路显示。
- 移动平台不可放门。其路径避开固定码头，可能在碰到玩家/其他实体时安全停住，以防夹入墙体；松开移动、等平台或R重试。第41关自主电梯复位后会继续运行，重生首帧可能短暂相交，下一帧由引擎推出并正常承载；独立复测没有死循环或无法通关。
- 已修复并保留复现：移动物体后来占据传送门出口导致角色进入实体；动态阻挡与地形贴面导致光线穿透；接收器贴在薄墙后因接近光束端点而误激活。仍未穷尽所有未来地图中的动态交叠组合。
- 门洞72px，角色22×30；浅色短段、出口堵塞、门户重叠仍拒绝。端点命中会完整向内贴齐，不能绕过首个实体遮挡。绿色反射最多8次，激光最多16跳/4000px，避免封闭回路无限计算。
- 地图不以唯一解或次数硬锁限制玩家；普通跳跃/无涂层/无光路等教学对照覆盖关键介绍关，没有穷尽所有合法巧解。
- 存档仅保存解锁数及音量。旧unlocked=8可能只是刚解锁8，需通关8后才进9；不擅自补解锁或清空。开发验证隔离存档，未自动驱动真实鼠标点击全部菜单。
- 尚未做小时级性能/内存测试、全部显示器刷新率验证或人手完整通关。自动输入、GPU截图、鼠标映射与EXE启动分别记录，不能互相替代。

## 人工验收

1. 从桌面Portal Hop或builds/PortalHop.exe打开，确认50关总数、5页选关、原进度及音量保留。
2. 第9关测试高点换门窗口；第10–19关重点试蓝反弹/红加速手感。单材质关仍可用传送门。
3. 第20关学习引导激光；第23等双接收器关检查锁存与线路；第32/33/35关反馈空中开枪是否过于紧迫。
4. 第36关试绿面反射能否看清，第37关搭平台观察齿轮与凹槽；试站稳、跳离、返回、暂停和R。
5. 第50关按中文路线完成：反射点亮两灯，渡台、蓝反弹、红跑道和最后跳跃；反馈阶段提示是否足够。
6. 试R/死亡后门、光源、接收器、平台、门户复位，Esc冻结、F11/异比例窗口仍为同一960×540视野。
