# 已知问题与人工验收

当前为七关试玩版。用户反馈原第七关仍过不去，已要求并实施空中松键减速、出口仅保留速度大小和第七关降难度；新机制及难度仍等待人手试玩。此前前三关的认可属于旧物理基线，本轮新规则需要一起回归。

## 已知限制

- UI 当前为英文；README 和开发记录为中文。
- 新机制保留入门总速度，方向完全沿出口外法线；旧切向速度不再保留。空中无水平输入时90px/s²横向减速，按键空中加速度380、地面与跳跃/重力未改。90是本轮实施值，手感仍需用户试玩确认。
- 第二关必须先放高处墙门，离开起点平台后才能射到地板。下落时需调整水平速度，有一定操作学习成本。
- 第三关空降前应从高台先射天花板；高台可能遮挡下层部分瞄准角度。这是实体遮挡规则的结果。两条路线均有重复的自动通关记录。
- 第四关先放蓝门，再离台放墙红门。地板出口竖直向上，按A落到左侧高台；天花板出口竖直向下，需按D向右，可以落地前碰门过关。起点台遮挡规则保留，关内只有建议圈。
- 第五关新规则下建议出门后一直按D踩踏，三种守卫时机已通关；旧提前按A的路线可能撞守卫，已更换提示。过关仍不强制击败守卫；本轮自动验证的是踩踏路线，旧版绕过路线不作为新规则的通过证明。
- 第六关首次传送后需要在下落中重放蓝门，4种时机（第2/16/30/45物理帧）均已通关，约0.36秒的已测操作区间。实际鼠标移动、反应和无文字建议圈的难度仍需人工试玩。入关前有英文说明卡；R与暂停重启直接重试。
- 第七关窄挡板已移除，蓝侧台从(300,300)降到(240,380)，初始仍被起点台挡住，首次出门后即可瞄准。已验证两枪间隔18/36/54帧、±8px瞄准及较晚首枪四组路线，竖直出门后立即D，均落台通关。54帧约0.45秒是已测两枪间隔，不代表完整的人手可用窗口；底层安全，可R重试。
- 浅色段边缘命中会将完整72px门向内贴齐，斜射精确墙角可选实际可见的浅色面；这不会绕过射线遮挡。若段本身短于72px、调整后出口堵塞或与另一门重叠，仍会拒绝，失败保留原门。
- 当前为用户选定的B圆润美术方向：旗帜/拱门已经原生绘制，关内不显示顶部文字。原有计时和死亡数仍在结算保留，新外观等待游戏内验收。
- 旧存档只记录解锁到哪一关，无法区分刚解锁和已经通关；旧unlocked=6需要通关一次第六关解锁第七关，旧3/4/5同理。不会自动清空或额外解锁存档。
- 按 R 从检查点复位并计一次死亡；暂停菜单的重新开始则清零本关时间和死亡数。
- 已有落地压缩、踩踏拉伸与光环、传送闪光，仍是简易几何动画，最终节奏和力度需要试玩反馈。
- 原音频退出警告已通过复用播放器、停止并释放音频流、退出前等待混音清理处理。第四关回归还复现快速切换后立即退出时60ms等待偶尔不足，现退出时先释放播放器并等待300ms，连续6次立即关闭通过；尚未进行小时级内存测量。
- 门洞沿承载矩形厚度切通，因此未来加入特别薄的双面可放门墙、相交门户或不同高度的复杂连续表面时，应扩充测试。当前七关和四朝向测试通过。
- 已测试间距90px的相向门在新减速规则下连续49次穿越，未卡死且速度有界；旧版本54次及精确900恒速是历史结果。三种窗口比例及全屏检查通过；鼠标自动定位需要避免实时光标移动干扰，结果见本轮验证记录。小时级循环及全部刷新率仍未穷尽。
- 本次没有自动驱动真实鼠标点击全部菜单，也没有做小时级性能/内存测量。已检查实际GPU渲染截图、鼠标坐标、脚本物理和EXE启动，不把这些等同于完整人工试玩。

## 人工验收步骤

1. 双击 builds/PortalHop.exe或桌面Portal Hop快捷方式（唯一入口，包含最新七关）；确认主菜单、操作说明、音量滑杆正常。
2. 首次关卡选择只应解锁第一关；完成后返回确认后续解锁，重启确认保留。
3. 七关按README新路线分别完成，重点反馈空中松键是否容易控制、出口方向是否符合预期，以及第七关是否能更轻松完成两枪和立即D落台。第六、七关入关卡和R重试仍保留。
4. 试放单扇门：仍为实体；两门后可穿越。瞄准浅色墙段两端和精确墙角，观察完整门向内贴齐；试同色替换、无效射击、两颜色反向进入和门边缘擦碰，观察是否符合规则。
5. 坑底尖刺、敌人侧面接触应立即触发死亡；复活应在起点、清门且敌人恢复。
6. Esc暂停期间，角色、敌人和计时停止；继续恢复，返回菜单可重新开始。
7. F11和设置按钮切换全屏；调整窗口尺寸，不应获得额外视野/射程。
8. 重点反馈第二关下落瞄准与刹车难度、第三关踩踏手感、音效音量和教学清晰度。

## 后续开发

第七关已实现；先收集用户试玩反馈，再决定修改或新增内容。推荐路线验证连续两次传送和空中两枪，不用传送次数硬锁终点；标准初始门对及普通跳跃对照未通关，但没有穷尽所有角度与跳跃组合的合法巧解。继续通过levels/maps.gd定义地图，Maps.LEVEL_COUNT统一驱动数量、解锁和最终页；guard字典可指定守卫坐标，默认值仍属于第三关。不自动开始第八关。
