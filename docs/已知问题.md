# 已知问题与人工验收

这是首版三关 MVP，不代表手感、平衡和所有极端情况已经完成最终验收。

## 已知限制

- UI 当前为英文；README 和开发记录为中文。
- 第二关必须先放高处墙门，离开起点平台后才能射到地板。下落时需调整水平速度，有一定操作学习成本。
- 第三关空降前应从高台先射天花板；高台可能遮挡下层部分瞄准角度。这是实体遮挡规则的结果。两条路线均有重复的自动通关记录。
- 按 R 从检查点复位并计一次死亡；暂停菜单的重新开始则清零本关时间和死亡数。
- 几何角色目前以站立、方向、空中轨迹、高速速度线、死亡圈提供反馈，尚未制作丰富的压缩/倾斜动画。
- 自动退出时 Godot 偶尔报告 AudioStreamWAV / AudioStreamPlaybackWAV 资源释放警告（verbose 已定位音频资源），通关断言仍全部通过；尚未证实是游戏运行期间持续增长的问题。独立启动日志未见脚本错误。
- 门洞沿承载矩形厚度切通，因此未来加入特别薄的双面可放门墙、相交门户或不同高度的复杂连续表面时，应扩充测试。当前三关和四朝向测试通过。
- 对极近相向门、长时间循环、不同刷新率和窗口比例未做穷尽测试。
- 本次没有自动驱动真实鼠标点击菜单，也没有做小时级性能/内存测量。已检查实际GPU渲染截图、脚本物理和EXE启动，不把这些等同于完整人工试玩。

## 人工验收步骤

1. 双击 builds/PortalHop.exe；确认主菜单、操作说明、音量滑杆正常。
2. 首次关卡选择只应解锁第一关；完成后返回确认后续解锁，重启确认保留。
3. 三关按 README 路线分别完成；检验正常跳跃无法直接跨前两关大坑、第三关小坑能跳过。
4. 试放单扇门：仍为实体；两门后可穿越。重新放同色门、无效射击、从两颜色反向进入、门边缘擦碰，观察是否符合规则。
5. 坑底尖刺、敌人侧面接触应立即触发死亡；复活应在起点、清门且敌人恢复。
6. Esc暂停期间，角色、敌人和计时停止；继续恢复，返回菜单可重新开始。
7. F11和设置按钮切换全屏；调整窗口尺寸，不应获得额外视野/射程。
8. 重点反馈第二关下落瞄准与刹车难度、第三关踩踏手感、音效音量和教学清晰度。
