# 第五关：The Final Relay / 终章接力

目标：沿用已确认手感、B圆润美术和无文字关内界面，制作综合弹射、落点控制、守卫踩踏及短缺口的第五关。用户已直接要求开发，完成后交付试玩。

## 地图初稿与通关路径

- 起点高台x190..330，顶部145，出生(260,130)。
- 左墙右向面x120，建议蓝门中心(120,90)，高出口避开起点平台。
- 左地面x0..490、顶部470，建议红门(440,470)，有效段390..490。
- 守卫平台x650..810、顶部390；守卫中心(720,373)，范围680..760、速度70。
- 终点平台x865..960、顶部350；普通跳跃或踩踏反弹可越过最后55px缺口。
- 底部空隙沿用现有致命深坑。死亡/R复位、清门、恢复本关守卫。

标准路线：从起点放蓝墙门；向右离开高台后放地板红门，A逐渐刹住，落进红门。出门向右飞跃，经过x260附近后按A减速，从上方踩中守卫并反弹，再按D向终点调整。备选路线保持向右越过守卫，在终点平台边缘起跳。不添加固定发射速度、敌人击败条件或新机关来强制路线。
