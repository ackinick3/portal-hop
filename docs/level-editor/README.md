入口：[关卡编辑器.html](../关卡编辑器.html)。单个离线文件，用普通浏览器打开即可；不需账号/网络/服务器。默认空白960×540白纸，旧浏览器若已有保存则恢复旧布局，可用“新建”清空（先导出备份）。旧五关批注网页继续保留。

## 画部件

- 起点/终点：选工具后点击；每张图各一个，再次放置会移动已有的。标记锚点分别是旗杆脚、终点门底部。
- 灰、白、蓝、红、绿墙：拖动绘制粗线段。白墙有灰色轮廓，在白纸上可见；斜墙直接斜着拖。选中后修改坐标、长度、线段角度和墙厚。
- 地刺：拖出基线，尖刺默认在拖动方向的左侧；右侧属性可改长度、角度、刺高，并“翻转地刺朝向”。角度0°向右、90°向下、180°向左、270°向上。
- 黄/紫/红激光发射器：点击放置，属性填朝向角度或用四个方向按钮。短箭头仅标方向，不是模拟光路，不定义三色激光的最终玩法。
- 激光接收器：点击放置；本工具未增加未要求的机关连接、信号或开门规则。
- 怪物：点击放置，默认不移动。选中后“启用移动范围”，或点“在画布拖动设置范围”再拖线；怪物放在范围中点，属性可改范围长度、方向。移动整只怪物时范围同步平移。

## 画预期路线

选择“曲线箭头”，拖出起点和终点，自动切到选择模式；拖动金色控制点改变弯曲，两端也可拖动。路线按创建顺序编号；需要折返或多段接力时画多条曲线。选中曲线后可直接填终点/控制点坐标。

曲线表达用户的预期走法。导出JSON发回对话后，助手读取部件、箭头创建顺序和说明，计算并调整间距、落差、坡角及必要比例。普通评图模式更新计划图供确认；调用[portalhop-level-builder技能](../../skills/portalhop-level-builder/SKILL.md)则已授权自主完成比例调整、实装、真实输入通关/回归和导出，之后汇报，无需再确认比例稿。发送`使用 $portalhop-level-builder，地图JSON：<文件路径>`即可。这里的网页不模拟人物/激光碰撞，手画轨迹本身不是可达证据。

## 修改与保存

- 选择/移动：点击已有部件，拖动整体移动；墙/刺两端、曲线两端和金色控制点可拖动。部件列表也能选中。删除键或“删除选中部件”删除，Esc回到选择模式。
- 数值改完按Tab或点击别处生效；越界会提示。普通拖动可画任意方向，属性角度更精确。
- 撤销/重做：按钮、Ctrl+Z、Ctrl+Shift+Z，最多80次，历史仅限本次打开。网格与放大为查看辅助；PNG导出不带网格/选择框/控制点，但保留路线及怪物范围。
- 自动保存到当前浏览器和打开地址，不写回HTML文件。重要布局请用“保存 / 提交 JSON”落盘；新建另一关前先导出。布局与说明一起导出。
- “载入 JSON”载入本工具导出的布局，替换前需确认；格式错误不会覆盖原图。五关批注JSON属于另一种格式，不能当成布局JSON导入。
- 浏览器存储不足时提示另存JSON；旧布局无法解析时保护其原始字符串、禁止自动覆盖，允许下载恢复备份。明确新建/载入后才替换旧存储。
