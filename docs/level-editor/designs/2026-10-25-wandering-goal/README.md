## 保留的路线

1. 起点向右跳跃，进入左侧落差；空中按A收横向速度，对准底部白墙上的入口，左白竖墙的出口向右。
2. 靠落差速度水平抛出，避开上下巡逻怪，飞越刺坑，真实落在红跑道上。怪物沿用70px/s及既有踩踏/侧碰规则，不改成不可踩怪。
3. 按D蓄速通过阻枪光幕，到右侧后正常射击换两门：右竖白墙入口、右白斜面出口。红跑道与竖门接齐，地面冲门不需要额外推力。
4. 斜门向左上出门后松横向键，落上移动平台。终点固定在平台上跟随真实碰撞体；本关要求实际站在平台上并接触终点，不能只从空中擦过终点区域。落点偏右时可在台上微调。

门均可自由放置，测试从实际gun_origin射击，不锁死门位。标准参考：左出口约(124,174)，底入口约(200,335)，右竖入口实际被完整开口内贴至(800,314)，斜门中心约(840.43,175.43)。这是参考门位，不是吸附点。
