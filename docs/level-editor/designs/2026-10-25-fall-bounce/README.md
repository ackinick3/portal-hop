**底部缩白带是需复核的玩法取舍。** 若整条底面可放门，可在底部同时放两门：落差化为向上弹射、空中按D，即可绕过蓝面落在终点台。本模型复现落台x743。白带缩至120px后，两扇72px门无法同时完整内贴；现有门位规则还要求两门中心至少76px，而该白带允许中心最大间距仅48px。角色仍可在有效白带内自由放门，没有定点吸附或关卡速度奖励。用户若希望允许巧解，可恢复长白带；本稿未把收短记为已获最终批准。

## 标准路线

1. 从起点走到右沿参考站位(235,185)，视线才看到底面和右白面；初始出生(131,185)射线会先碰起点地面。先放底面门参考(420,500)，以及右白面外沿参考(630.4,299.3)。两色可对调。
2. 放好门后退回约x160，按D向右助跑，越过平台边沿时达到210。模型从(243,185)、速度(210,0)开始下落估算；**保持D直到进底部门**，否则横向松键减速会改变落点。
3. 出门后松开横向键，向左飞行触蓝面，自动向右上反弹；飞行段使用现有90横向减速，不额外加推力。
4. 实际落在右侧平台，再向右走到终点。失误沿用R清门/回出生；不增加教学卡或关内解法提示。

## 计算证据

用当前源码中的900重力、120Hz步长、210普通跑速、90空中松键减速、22×30角色；蓝反弹沿用`incoming < 0`与切向保留、最低法向580/420、上限900公式。

计算对20px墙带做角色AABB的Minkowski扩张并扫掠检测，以防只按中心曲线穿过墙角。模型将墙带按平头矩形处理；编辑器的圆端只是示意笔触。斜面门采用拟实现的完整72px切口、法线出口、AABB投影安全间距和入门切向偏移；**这些斜面几何尚不在实际游戏中实现**。
