## 标准通关与重试

1. 向右走，在起点右沿约(182,125)站位放斜面出口，参考门中心(249.24,213.35)。初始位置的射线受地形限制，不能穿台放门。
2. 继续按D跑下平台，离台后约(234,138)处可向底面(365,400)放另一门，保持D直至真实进入底门。无需起跳。
3. 第一次斜面出门立即按A，用现有空中反向加速度收水平速度；转入下落时，将底门移到约(635,400)。记录中换门枪口约(501,61)，视线无遮挡。
4. 第二次出门松开横向键，实际落到右上平台，再向右走到终点。失误R清门/计数回出生；不增加关内解法提示。

参考门位可自由变化，不是吸附点。截图测试的等待绘制帧未作为生产特殊处理。
