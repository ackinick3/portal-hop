这只是参考解法。用户已确认自由解法，因此保留四面白墙和其他合法放门/踩怪方式；不要求每一只怪或移动刺台都参与同一次通关。当前参考路线可以较快完成，难度与其他解法待用户实玩反馈，不把快速通关当成必须封堵的绕路。
