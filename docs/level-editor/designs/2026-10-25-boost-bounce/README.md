## 必要的新机制支撑

旧player只查脚下向上法线的红地，真实测试在红坡掉到横速约277、竖速+30、红距离196，不能自然上坡起飞。新逻辑仅在落地、碰撞法线匹配floor、接触点命中红patch时，沿实际地面切线驱动。目标650、按键加速度1800、松键2300保持；普通地面、非红斜面、水平红地、蓝反弹及传送公式均走原路径。

新测试实际跑上坡，松键刹车后重新加速，离坡采样横速约598、向上约127，红距离286，通过；名义不刹车路线离坡后采样约(622.63,-141.64)。采样在越过x455后，已包含几帧重力，不声称是离沿瞬时的理想切向矢量。未扩大原可行走坡度范围；竖直红墙不作为可站立加速坡，反向/跳跃/混材边界未专项穷尽。

## 标准路线与实测

按D蓄速，在红坡上正常射击：记录中左斜面出口枪口约(373,405)，右斜面入口约(394,399)，均有真实首表面视线。参考出口中心(95.45,225.06)，入口(733.55,404.27)，没有固定门位吸附。越坑入右门后松横向键，落蓝台后自动反弹；实际落上终点台，再按D向右到终点。无需跳跃键。

名义0死亡、1传送、1蓝反弹，实际落台约(712.26,84.93)，最高角色中心约31.4，上沿约16.4，无顶屏。名义+4组附近门位通过（入口沿面±6、出口±4独立扰动），落台/胜利均为真实输入，不修改角色位置/速度或直接complete。移除红加速的同输入在刺坑死亡；移除蓝反弹则只能留在中台，不能到高终点。这是机制剥离对照，不是生产游戏新增选项。
