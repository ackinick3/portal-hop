# 第29关：THE BORROWED EXIT／借来的出口

这是用户要求助手自行设计并立即生成的高难解谜关，不来自用户JSON。稳定ID56，追加于原28关之后。下面包含完整解法；试玩前不必阅读。

## 设计与取舍

难点在可见空间的连接顺序、光路与放门用途转换。没有新增怪物、限时机关或改变普通角色/传送物理。三个接收器使用现有锁存规则，不引入额外状态机。

房间内沿x40–920、y60–500。上层地面y250，左侧至x560，右侧从x780开始，井宽220。下层地面y500，安全容纳错误路线，R从任意阶段清门、清信号、关门并重生。没有改写用户进度或解锁记录。

首道门顶y160，离地90，普通跳跃脚部最大上升约60.5，因此不能直接翻过。它上方的光幕x210/y85–160只阻枪，顶部留下25px光线窗口，不能容纳30px高的角色。顶端绿面x150–260/y60提供反射。激光入口白面x260/y84–164，门中心被完整72px开口约束在y120–128，普通跳跃不能把整个角色送入。

两个上层光路出口都在y60天花板，离上层地面190，不能作为普通跳跃可进入的捷径。普通满速完整跳跃水平位移约154px，远小于220px井宽（即使考虑角色半宽仍不足）。下层第三个白面x800–900/y500；终点室出口x920/y150–240。相邻自由门位仍适用同一碰撞、射线和端点内贴规则。

初稿终点x790，较高返回门位会在真正落台前擦到终点；实测后移至x780，九组路线都先实际落台再完成。不是通过改变传送公式扩大容差。

## 标准解法（剧透）

1. 出生(90,235)，枪口(90,239)。瞄准顶端绿面约(213.20,60)，反射到白面(260,128)，放红门。计算使用镜像点(260,-8)，实际鼠标目标位于屏幕内的绿面，绝不要求鼠标移出窗口。
2. 蓝门放在(100,60)，激光向下点亮access接收器，第一道门打开。
3. 进入中间室，保留红色激光入口，将蓝门换到(450,60)，点亮well接收器，打开井口门。
4. 走到井口边缘约(557,235)，蓝门换到(840,500)。激光点亮下层return接收器，终点室门打开。
5. 接收器已锁存，红门不再需要维持激光。将红门换到终点室(920,200)，保留低处蓝门。
6. 向右下井，实际落到下层并走进低处门，从右侧出口回到上层。用正常方向键减速，落到终点平台后向左走进终点。

参考路线0死亡、1次真实传送。并不按传送计数触发胜利，静态终点仍由原有实际位置检测完成。没有强制预设门位、直接设置速度、摆位通关或调用complete作为路线证明。省略第5步会返回原激光入口附近而非终点室；仍可回到井口重新安排，或R重试，不故意制造不可恢复的陷阱。
