# 第36–50关标准路线与验证

本章地图在`levels/advanced_rooms.gd`，索引35–49；继续使用现有玩家物理与B风格。坐标均为960×540逻辑坐标；鼠标瞄准点是从实际枪口发射的目标，不是角色或门户的强制坐标。放门仍自由、射线停在首个实体，绿色只反射枪线，不反射激光。关卡内没有文字HUD。

移动平台有实体碰撞、轨道及齿轮，普通站立玩家靠Godot平台速度随行；平台本身不能放门。平台运行轨迹与旁边固定平台留至少10px水平净空，避免安全边距把电梯误卡在相邻平台底面。落到下层或漏接平台后可R；R清门、清接收器锁存、关门、复位平台，暂停冻结运动。

## 标准路线

| 关 | 名称与几何重点 | 实际操作路线 |
|---|---|---|
| 36 | THE GREEN DETOUR：天花板反射、中央高隔墙 | 起点不动，右键瞄绿色天花板约(370.5,60)，枪线反射后在右岸(650,400)放蓝门；直接瞄右岸会被中墙挡住。左键起点浅色地板(180,400)，按D进入红门，出蓝门后继续D到右侧终点。无需跳跃或空中射击。 |
| 37 | THE GEAR FERRY：宽坑横向渡台 | 从平台上出生，松开移动键搭乘。平台左边到x≈675（即接近右端）时D+Space跳向x810开始的右岸，继续D到终点。普通跳跃不能跨越整道坑。 |
| 38 | LIGHT THE TRACK：反射激光出口、动力渡台 | 出生在停驻平台右缘，左键中墙(400,220)。右键绿色地板约(379.2,480)，反射后在远墙(900,200)放蓝门，激光从蓝门向左点亮(750,200)。平台启动后不动搭乘，到左边x≈738时D+Space上右岸，继续到终点。中心位置向下射击会被平台自身挡住，出生站位已避开此遮挡。 |
| 39 | BEHIND THE LIFT：反射跨墙后换乘电梯 | 先照36关放两门并D通过。到右岸x≈745停住，等电梯回到y≈386以下，D+Space跳上电梯，空中用A/D修正至x≈830；落稳后松键。平台升到y≈215以上时D+Space跳右上终点。 |
| 40 | RUNWAY TO THE LIFT：红色跑道下落跨坑、电梯升层 | 起点按D，红色跑道加速后直接跑离x350边缘，不跳、不在坑中松键。越过x≈500后用A逐渐刹车，落到x600–750、顶500的低岛，在x≈710停住。等电梯低至y≈486，向右跳上x≈815，松键上升；到平台y≈285时D+Space跳右上终点。 |
| 41 | THE UPPER BRIDGE：先升层再搭门户桥 | 原地搭电梯，从y450上升到y≈232时A+Space跳左上小码头，停在x≈50、等待落地。先右键远岸浅色地板(850,220)，再左键脚下(50,220)，按D穿红门到远岸，继续右走到终点。 |
| 42 | MINT SKYLINE：反射过墙、蓝色反弹登高 | 和36关同样预放双门、按D穿过。继续D，踩右岸x710–840的蓝色涂层后自动反弹，保持D越过高台左边，在右上出口处结束。无需额外按跳。 |
| 43 | THE LIGHT ELEVATOR：反射点亮信号、竖直载台 | 左键中墙(400,220)，右键绿色低层地板约(370.5,500)，反射到远墙(900,200)。接收器点亮后电梯上升，原地随行；到y≈212时A+Space跳左上码头终点。 |
| 44 | THE RETURN RAIL：左行激光与回程渡台 | 从右侧平台左缘出生。左键中墙右面(560,220)，右键绿色地板约(580.8,480)，反射到远左墙(60,200)。激光向右照亮接收器、开码头门并启动左行平台。松键搭乘，到平台左边x≈115时A+Space跳向左岸终点。 |
| 45 | BOUNCE TO THE FERRY：蓝色上升、中岛换乘横台 | 按D跑到低层x210开始的蓝色涂层，自动反弹后保持D，落到x340–520、顶320的中岛；在x≈475停住。等渡台回到x≈545以内，D+Space跳上它，空中修正到台面中部、落稳松键。平台接近x≈767时D+Space到右端终点。 |
| 46 | THE REFLECTED RUNWAY：反射进中岛、红色跨末坑 | 右键瞄绿色天花板约(333.6,60)，反射到中岛(575,400)；左键起点(180,400)，D穿门。继续D，落到中岛红色末段后加速，在x≈680时Space跳过至x900开始的末岸，继续D到终点。 |
| 47 | SWITCH THE SIGNAL：先驱动平台，再改门开独立门锁 | 先按38关方法点亮第一个接收器并启动渡台。保持红门(400,220)，把蓝门改到远岸浅色地板(845,400)，向上出射的真实光束点亮第二接收器(845,160)。两信号锁存；松键搭乘到平台x≈670时D+Space上岸、穿已开的门到最右终点。 |
| 48 | TWO GREEN HORIZONS：地板反射升层、天花板反射换岸 | 左键(400,220)，右键绿色地板约(411.8,500)，反射到远墙(900,280)，光束点亮(750,280)，启动电梯。搭乘至y≈212后跳左上码头，停在x≈50。右键绿色天花板约(437.1,40)，这次反射到远上岸(850,200)；左键脚下(50,200)，D进入门户至右上终点。 |
| 49 | THE DOUBLE BANK：两次绿色反射后蓝色上升 | 右键瞄天花板约(616.4,60)，枪线先反射到右墙绿色面，再反射到右岸(650,400)；直接瞄右岸会被隔墙挡住。左键(180,400)，D穿门并继续右走，落到蓝色涂层后自动反弹，保持D到x820–860小高台上的出口。转弯路径与高台没有穿模；两段反射均有检查。 |
| 50 | THE COMPLETE CIRCUIT：完整机制串联、回到左上终点 | 左键(400,220)，右键绿色地板约(379.2,480)，反射后在(900,200)放蓝门，点亮平台接收器。再把蓝门改到同墙(900,260)，激光点亮(850,260)，打开蓝色落台前的门。两接收器已锁存，无需维持第一条光线。原地搭乘到平台x≈688时D+Space跳右岸，飞至x≈835后松Space、按A。蓝色落台反弹后持续A，在上方x500–730、顶250的红色跑道落稳。继续A加速，在x≈520时Space向左跳过末坑，落左上平台并向左到最终出口。 |

## 实际检查

```powershell
& './tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe' --headless --fixed-fps 120 --path . --script tests/advanced_routes.gd --log-file docs/advanced-check.log
```

可追加`-- --room=50`，或`-- --from=36 --to=40`，定位某关。测试从正式`main.tscn`实例及每关真实出生点开始，仅通过移动/跳跃输入和从实际枪口调用射击来完成路线；不强制玩家坐标、速度、接收器或完成状态。每关要求`state=won`且零死亡，并检查其地图包含的绿色反射、平台随行及材质是否实际使用。

2026-10-25实跑：15关全部零死亡通过；第50关平台随行约588px、蓝色反弹1次、红色加速约187px。介绍关另有去掉绿色反射后的隐藏目标失败、36关普通跳跃无法绕过、37关停驻渡台时无法跳过宽坑的对照。第50关通过真实两次光路开启接收器后，暂停冻结平台/角色/机关计时，R清接收器/门/门户并复位平台相位。完整输出见`docs/advanced-check.log`；最初缺少章节时的失败见`docs/advanced-before/check.log`。

本章未自行运行GPU预览、导出或全项目回归，留给主任务统一检查。自动通关不代表人手难度已验收。固定帧率下模拟计时快于真实音频线程，测试退出前另留350ms真实时间让音频混音资源释放。
