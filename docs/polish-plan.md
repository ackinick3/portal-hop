# 三关体验与稳定性打磨计划

用户已同意依次改善教学/路线、动作反馈和稳定性。规格仍以任务书.md为准，地面松键减速保持2300，空中控制380，重力900及传送向量规则不变。

**Goal:** 三关更容易理解、关键动作有反馈、退出与显示模式有可重复验证。
**Architecture:** 增加小型教学提示脚本，由现有门状态、位置和本次生命内传送次数决定提示。动画只在绘制中变换，声音使用每种音效一个可复用播放器并明确关闭。
**Tech Stack:** 现有Godot 4.7.2 / GDScript。

## 验证重点

- 第二关起点平台遮挡地面射击时，提示必须说明离开平台后再放地板门，不能引导穿墙。
- 区域标记只是建议，仍然自由放门。
- 第三关两条路线继续可通关；传送路线明确说明先从高台射天花板。
- 落地/踩踏/传送动画不改变碰撞体、速度或操控参数。
- 暂停停止物理、计时、教学进度与动画；音频节点不随播放次数增长。
- 连续传送不能原地重复触发或进入实体，调整窗口和全屏不得扩大逻辑视野。
