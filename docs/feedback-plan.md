# 试玩反馈调整

范围：第三关仍允许普通跳跃踩踏；只调整持枪瞄准、移动手感和射击反馈。

1. 枪以手部为轴随鼠标转动；射线仍从角色碰撞体内部发出，避免枪管穿墙导致绕过遮挡。验证上下左右、斜向和鼠标与手部重合。
2. 按用户补充，只把地面松键减速从1400调到2600，缩短滑行距离；地面起跑加速度1400、空中控制380、空中松键漂移及传送弹射全部保持原样。验证普通跑停及空中行为未改变。
3. 每次开枪显示0.18秒对应颜色的射线和命中圈，轨迹止于第一个实体；无效材质也显示被挡住的命中点。验证遮挡、淡出及死亡清理。

执行：先运行新增测试确认旧版本失败，再实现并重跑全部通关测试；实际渲染检查后重新导出Windows EXE并提交Git。
