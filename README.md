# Portal Hop

Godot 4.7.2（官方稳定版）、GDScript、Windows x64，五十关单机试玩版。

**开发接续入口：[PROJECT_STATE.md](PROJECT_STATE.md)**。新对话先读这份项目现状与接续指南；`AGENTS.md`要求后续修改时同步维护它。历史开发记录仍保留在`docs/进度.md`。

## 直接游玩

双击 `builds/PortalHop.exe` 或桌面 **Portal Hop** 快捷方式，当前包含五十关和B美术。后续持续更新同一个文件，不另分关卡版或美术版。资源已嵌入 EXE，无须安装 Godot。

- A / D：移动、有限空中调整；空中松键会轻微降低横向速度
- Space：跳跃，长按跳得更高
- 鼠标左 / 右键：红 / 蓝门
- 空中也能开枪；重放同色门会替换原来的门，另一颜色保留。
- R：死亡重试，清除门并复位敌人
- Esc：暂停；F11：全屏切换
- 只有浅色表面能放门；准星绿色表示当前红门可放，红色表示失败。
- 命中浅色段边缘时，整扇门会沿同一表面向内贴齐；预览显示实际落点。短于72px、出口堵塞、两门重叠或被其他实体挡住仍不能放门。
- 枪口随鼠标瞄准；开枪时显示短暂的红/蓝轨迹，遇到第一个实体就停止。
- 地面手感保持原值。空中松键仅横向以90px/s²缓慢减速，不影响竖直重力和跳跃；按住移动键仍可保留高速弹射。
- 门只保留入门时的速度大小，出门方向完全由出口决定：地板向上、天花板向下、墙面向外。例如以(300,400)入门，总速度500，向上出口给出(0,-500)。
- 设置支持主音量。进度与设置保存于 `%APPDATA%/Godot/app_userdata/Portal Hop/progress.cfg`。

## 打开和运行源码

在项目根目录运行 PowerShell：
```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64.exe --editor --path .
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --path .
```

逻辑视野 960×540，默认窗口 1280×720，保持 16:9。使用 OpenGL Compatibility。
编辑器已通过实际启动检查。程序化几何图形和合成音效为本项目生成，无外部游戏素材。
场景入口 `scenes/main.tscn`；地图 `levels/maps.gd`；角色和传送系统可复用。

还覆盖出口仅继承总速度并沿外法线、空中松键减速、动态教学、动作反馈、音频清理、暂停、近距离连续传送、第四关两种出口、第五关三种守卫时机、第六关空中换门增速，以及第七关两枪间隔（18/36/54帧）、±8px瞄准、边缘出口不撞底和按D落台。第八关预放双门后持续D、三组相邻门位、错误出口高度和R复位均有检查。入关卡、旧存档解锁、第四至八关普通跳跃绕过对照均有检查。边缘专项覆盖四朝向贴齐、精确墙角斜射、预览/实际一致和拒绝条件。共33组无界面测试；完整捕获运行输出，运行时错误及退出泄漏警告会使测试失败。

窗口/鼠标/全屏检查需要真实图形窗口，单独运行：
```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --path . --script tests/display.gd
```
该检查会短暂调整其测试窗口、移动鼠标到测试点、切换全屏并恢复，不改变玩家存档。

## 导出 Windows

```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release 'Windows Desktop' builds/PortalHop.exe
```

使用 `export_presets.cfg` 指定的本地官方 Windows x64 模板；只从完整模板包提取 Windows 文件。
便携引擎和模板在 tools 中，不修改系统 PATH，也不进入 Git。交给其他电脑开发时须自行从官方取得相同版本工具。

## 试玩路线

按用户选择，旗帜和终点门采用白色圆角、绿色灯带的B风格。关内顶部文字和建议点标签已移除；无文字建议圆圈、准星和放门预览继续保留，门仍能在整个有效表面自由放置。计时/死亡数在结算查看，具体路线见下文。

1. 第一关：起点直接向浅色地面 x≈300 放红门，向右岸 x≈720 放蓝门。向右移动并跳进红门，出蓝门后继续向右到绿色终点。左边阶梯可用于额外下落高度，不是必经路线。
2. 第二关：从高台瞄准左墙靠近顶端 y≈90 放蓝门。走下高台右侧后，向下方 x≈465 放红门。用 A 逐渐刹住水平移动，落进红门。弹射后在右岸落地；越过终点时可以回走触发。
3. 第三关普通路线：走下高台，在守卫附近跳起，从上方踩中或绕过，再跳过末端小坑。
4. 第三关空降：先在高台向天花板 x≈510 放蓝门；从高台左侧下来，在下层向 x≈200 放红门。向右进入红门，从天花板下落时向守卫调整，踩踏后继续通关。
5. 第四关标准路线：先向右侧高台地板 x≈830、y=300 放蓝门。按 D 走下起点台右侧，离台后向墙面 x=310、y≈300 放红门，继续保持 D 落入墙门。出门后按 A 向左调整，落到终点高台再走向绿色出口。若失误落到底层安全地面，按 R 复位即可。
6. 第四关备选路线：先向天花板 x≈540、y=160 放蓝门；再像标准路线一样离台、放墙红门并进入。现在出口会竖直向下，出门后按 **D 向右**进入终点门；触到门即可过关，可以在落地前触发。

7. 第五关“终章接力”：先向左墙 x=120、y≈90 放蓝门。按 D 离开高台右侧后，向地板 x≈440、y=470 放红门；靠近红门上方时按 A 刹住，落入门中。出门后保持 **D 向右**，从上方踩中守卫，反弹后继续向终点。不再沿用旧版本出门后提前按A减速的路线；按 R 可清门并恢复守卫重试，过关仍不强制击败守卫。
8. 第六关“空中接力”：入关说明卡点 **START ROOM** 开始。从右上高台向天花板 x≈465、y=60 放蓝门，按 A 向左走下高台，离台后向地板 x≈465、y=480 放红门。靠近红门上方时短按 D 刹住，松开移动键继续落入红门。从天花板出来后，**人在空中时，立即用右键把蓝门改到左墙 x=120、y≈100；红门保留**。继续下落再次进入红门，随后按 D 向右飞到终点。两次真实下落速度约810→1178；传送本身保持速度大小，增加的速度来自第二次下落的重力。R直接重试，不会再次弹出说明卡。
9. 第七关“空中折返”：先放左墙蓝门(180,170)，按D走下起点台，离台后放地板红门(590,510)，接近x535时短按A刹住并松开，利用更长落差进入红门。向右飞行中，先左键红墙(820,420)，再右键蓝右下侧台(670,420)。第二次出门竖直向上，立即按D，落到右上方终点台，再向右进门。本轮提高自然落速，并移动出口/终点，避免上冲撞高台底面；物理没有改，底层安全，R重试。

10. 第八关“高路抉择”：入关卡点START ROOM。从起点先放高处蓝左墙门(100,90)，再放红地板门(430,480)，两扇门都能在移动前射到。之后一直按住D即可下落、弹射、越过矮墙并落终点台，不需要跳跃或空中开枪。蓝门放太低（例如y160）越不过障碍，可R重新布置；重点是预先选择出口高度。

旧存档继续保留原解锁数。通关第七关后点击NEXT ROOM进入第八关说明卡；旧unlocked=7可能只是刚解锁第七关，不会自动解锁第八关，需再通关一次第七关。旧3/4/5/6同理，不清空进度或补解锁。第六、七、八关都有独立说明卡，R与暂停重启直接重试。

## 新材质与机关（第9–50关）

- 蓝色带圆点的表面：接触自动弹开，用A/D控制落点。
- 红色箭头跑道：按住移动逐渐加速；离开跑道保留速度。
- 琥珀色激光台：持续发光，利用双传送门改变光路，照亮接收器后保持启动，控制线路连接的门或移动平台；R复位。
- 绿色墙/顶/地面：等角反射枪线，可以打到直接射击被挡的浅色面；绿色本身不放门。
- 带齿轮的平台：站稳随行，背景凹槽表示运行路线；部分需要接收器供电。平台本身不放门。

第9关练刺海换门接力；10–19逐步学习反弹/助跑；20–25学习激光；26–35混合三种机关；36–50加入反射面、渡台/升降台及综合路线。选关共5页，每页10关，保存原有解锁。**旧八关存档需通关第八关后解锁第九关**，不会自动补进度。最终结算只在第五十关出现。
