# Portal Hop

Godot 4.7.2（官方稳定版）、GDScript、Windows x64，四关单机试玩版。

**开发接续入口：[PROJECT_STATE.md](PROJECT_STATE.md)**。新对话先读这份项目现状与接续指南；`AGENTS.md`要求后续修改时同步维护它。历史开发记录仍保留在`docs/进度.md`。

## 直接游玩

当前B美术版双击 `builds/PortalHop-B美术版.exe`。资源已嵌入 EXE，无须安装 Godot。

- A / D：移动、有限空中调整
- Space：跳跃，长按跳得更高
- 鼠标左 / 右键：红 / 蓝门
- R：死亡重试，清除门并复位敌人
- Esc：暂停；F11：全屏切换
- 只有浅色表面能放门；准星绿色表示当前红门可放，红色表示失败。
- 枪口随鼠标瞄准；开枪时显示短暂的红/蓝轨迹，遇到第一个实体就停止。
- 地面松键后更快刹停；空中控制与传送弹射动量保持原来的规则。
- 设置支持主音量。进度与设置保存于 `%APPDATA%/Godot/app_userdata/Portal Hop/progress.cfg`。

## 打开和运行源码

在项目根目录运行 PowerShell：
```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64.exe --editor --path .
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --path .
```

逻辑视野 960×540，默认窗口 1280×720，保持 16:9。使用 OpenGL Compatibility。
编辑器已通过实际启动检查。程序化几何图形和合成音效为本项目生成，无外部游戏素材。
场景入口 `scenes/main.tscn`；地图 `levels/maps.gd`；角色和传送系统可复用。

## 自动测试

```powershell
./tests/run.ps1
```

覆盖基础移动、墙碰撞、跳跃、真实门洞、射线遮挡、材质与边缘约束、同色替换、失败保留、相邻表面合并、全部 16 种朝向的向量及真实物理穿越、低速及双向传送、出口重入、30,000 px/s 薄墙、四关实际移动通关、敌人踩踏及侧面接触、死亡清门和敌人复位。
第三关普通路线与天花板空降路线分别运行。测试不写入正式玩家进度。

本轮还覆盖动态教学状态、落地/踩踏/传送的绘制反馈、音频池与退出清理、暂停动画、近距离传送门连续穿越，以及第四关两条路线、放门偏移、旧存档解锁和已发现的普通跳跃绕过路线。共17组无界面测试；完整捕获运行输出，运行时错误及退出泄漏警告会使测试失败。

窗口/鼠标/全屏检查需要真实图形窗口，单独运行：
```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --path . --script tests/display.gd
```
该检查会短暂调整其测试窗口、移动鼠标到测试点、切换全屏并恢复，不改变玩家存档。

## 导出 Windows

```powershell
& ./tools/godot-4.7.2/Godot_v4.7.2-stable_win64_console.exe --headless --path . --export-release 'Windows Desktop' builds/PortalHop.exe
```

使用 `export_presets.cfg` 指定的本地官方 Windows x64 模板；只从完整模板包提取 Windows 文件。
便携引擎和模板在 tools 中，不修改系统 PATH，也不进入 Git。交给其他电脑开发时须自行从官方取得相同版本工具。

## 试玩路线

按用户选择，旗帜和终点门采用白色圆角、绿色灯带的B风格。关内顶部文字和建议点标签已移除；无文字建议圆圈、准星和放门预览继续保留，门仍能在整个有效表面自由放置。计时/死亡数在结算查看，具体路线见下文。

1. 第一关：起点直接向浅色地面 x≈300 放红门，向右岸 x≈720 放蓝门。向右移动并跳进红门，出蓝门后继续向右到绿色终点。左边阶梯可用于额外下落高度，不是必经路线。
2. 第二关：从高台瞄准左墙靠近顶端 y≈90 放蓝门。走下高台右侧后，向下方 x≈465 放红门。用 A 逐渐刹住水平移动，落进红门。弹射后在右岸落地；越过终点时可以回走触发。
3. 第三关普通路线：走下高台，在守卫附近跳起，从上方踩中或绕过，再跳过末端小坑。
4. 第三关空降：先在高台向天花板 x≈510 放蓝门；从高台左侧下来，在下层向 x≈200 放红门。向右进入红门，从天花板下落时向守卫调整，踩踏后继续通关。
5. 第四关标准路线：先向右侧高台地板 x≈830、y=300 放蓝门。按 D 走下起点台右侧，离台后向墙面 x=310、y≈300 放红门，继续保持 D 落入墙门。出门后按 A 向左调整，落到终点高台再走向绿色出口。若失误落到底层安全地面，按 R 复位即可。
6. 第四关备选路线：先向天花板 x≈540、y=160 放蓝门；再像标准路线一样离台、放墙红门并进入。出门后按 A 逐渐刹住向右动量，落到终点高台，转向绿色出口。

旧三关存档继续保留原解锁数。第一次运行四关版时，**重新通关第三关后点击 NEXT ROOM 解锁并进入第四关**；以后可以直接选关。旧存档没有单独记录“第三关已完成”，因此不会把所有 unlocked=3 的存档直接视为第四关已解锁。

完整阶段记录、地图调整原因、测试日志见 `docs/进度.md`；限制与人工验收见 `docs/已知问题.md`。
